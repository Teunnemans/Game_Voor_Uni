## Korte beschrijving van je game

Vul hier een korte beschrijving van je game aan (max. ongeveer 10 regels):

- **Idee:** <br>
    Mijn spel heet Space-Racer. Het is een eindeloze 2D-game waar je zolang mogelijk 
    Vijanden ontwijkt. Dit wordt steeds moeilijker. Om je te helpen zijn er soms powerups.
- **Functionaliteiten:** <br> 
    Ik wil sowieso goede movement in mijn game, iets dat wat verder gaat dan gewoon x-pixels/seconde verplaatsen.
    Verder wil ik een powerup-system, interessante enemies en een aesthetische art-style. Ik vind het leuk mijzelf uit te dagen
    Om te kijken of ik een goed geoptimaliseerd spel kan maken, zeker omdat python niet de snelste taal is. Ik wil dit doen door OOP te gebruiken.
    Dit maakt code vaak leesbaarder en modulairder. Als ik tijd over heb dan wil ik toevoegingen aan de gameplay maken. Deze zijn nader in te vullen.
- **Besturing:** <br>
    De speler kan met de pijltjestoetsen bewegen. Verder heeft de UI knoppen om het spel te bedienen.
